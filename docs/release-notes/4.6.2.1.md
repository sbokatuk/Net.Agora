## Net.Agora 4.6.2.1

First release. One cross-platform Agora Video (RTC) client for .NET MAUI, over
[Net.Agora.iOS](https://github.com/sbokatuk/Net.Agora.iOS) and
[Net.Agora.Android](https://github.com/sbokatuk/Net.Agora.Android).

```csharp
var client = new AgoraVideoOptions { AppId = "your-app-id" }.CreateClient();

client.SetLocalView(LocalView);          // a <agora:AgoraVideoView /> from your XAML
client.UserJoined += (_, e) => client.SetRemoteView(e.Uid, RemoteView);

await client.JoinAsync("my-channel");    // completes when the server confirms
```

### What is in it

- **`Net.Agora.Video`** — the cross-platform client: `IAgoraVideoClient` over the native
  `RtcEngine` / `AgoraRtcEngineKit`, with an awaitable `JoinAsync` (server-confirmed, with
  timeout-versus-cancellation semantics), `Joined` / `Left` / `UserJoined` / `UserOffline` /
  `Error` events, and media toggles.
- **`Net.Agora.Video.Maui`** — `AgoraVideoView` plus its handler, `UseAgoraVideo()` registration,
  and `SetLocalView` / `SetRemoteView` extensions that connect a client to MAUI views.

### Versions underneath

The version tracks the iOS native line, `<native>.<binding revision>` — the two platforms never
ship the same number, so this package pins each binding exactly:

- Net.Agora.Video.iOS **4.6.2.1** (AgoraRtcEngine_iOS 4.6.2)
- Net.Agora.Video.Android **4.6.3.1** (io.agora.rtc:full-rtc-basic 4.6.3)

### Coverage

Unit tests for the platform-neutral logic, package-layout tests against the packed `.nupkg`, and
on-device smoke tests (simulator and emulator, in CI) that join-fail, cancel, time out, and dispose
against the real engines.
