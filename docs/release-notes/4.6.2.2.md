## What's changed

**Voice debuts**: `Net.Agora.Voice` and `Net.Agora.Voice.Maui` — the audio-only siblings of the
Video packages, over platform bindings (`Net.Agora.Voice.Android` / `Net.Agora.Voice.iOS`) whose
native artifacts carry no video codecs at all.

The Voice client is the same shape as the Video one — awaitable `JoinAsync` with a bounded
timeout, ordinary .NET events, one API across Android and iOS — plus the voice essentials:

- `SetSpeakerphone(bool)` — audio routing, before or during a call (the two different native
  calls that requires are hidden behind the one switch);
- `EnableVolumeIndication(TimeSpan)` + `VolumeIndication` — who is speaking and how loudly, with
  uid 0 meaning "you";
- `RemoteAudioMuted` — remote users' mute state;
- `RenewToken` + `TokenPrivilegeWillExpire` — production token rotation;
- `AgoraVoiceOptions.ClientRole` is applied at join (live-broadcasting voice rooms), and
  `DefaultToSpeakerphone` picks the starting route.

`Net.Agora.Voice.Maui` carries the platform glue only (`CreateClient()` supplying the Android
`Context`) — no view, because voice renders nothing.

```csharp
var client = new AgoraVoiceOptions { AppId = "your-app-id", DefaultToSpeakerphone = true }.CreateClient();

client.VolumeIndication += (_, e) => ShowSpeakers(e.Speakers);
client.EnableVolumeIndication(TimeSpan.FromMilliseconds(200));

await client.JoinAsync("my-room");
```

Pick one product per app: Video already carries the full audio surface, and the two products'
platform packages collide (same Java classes on Android, same `AgoraRtcKit` framework on iOS).

The Video packages are unchanged apart from the release mechanics (all façade packages ship from
one tag, so their binding revision advances in step).

## Tests and samples

- The unit tests cover `AgoraVoiceOptions` validation and defaults alongside the Video ones.
- The package tests assert both façades' target frameworks and exact platform pins.
- The on-device suite gained a product axis (`-p:AgoraDeviceProduct=Voice`): the same
  join/timeout/cancellation/dispose state machine runs against the packed Voice package on an
  Android emulator and an iOS simulator, plus the voice-only surface (mute, speakerphone, volume
  indication).
- `samples/Net.Agora.Sample.Voice` is a MAUI voice-room sample: join/leave, mute, speaker toggle,
  and a live who-is-speaking readout.
