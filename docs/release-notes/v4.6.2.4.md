## What's changed

`Net.Agora.Video` / `.Maui` and `Net.Agora.Voice` / `.Maui` advance to **4.6.2.4**, gaining the
switches that drive the twelve new RTC extension packages:

```csharp
client.SetNoiseSuppression(AgoraNoiseSuppression.Aggressive);   // + Net.Agora.Extensions.Ains.*
client.SetVirtualBackground(AgoraVirtualBackground.Blurred());  // + ...VirtualBackground.*
client.SetVideoDenoiser(true);                                  // + ...ClearVision.*
```

These are the one place in the façades where a native return code is not swallowed: without the
extension's payload the call compiles, links and then fails, so a refusal raises an
`AgoraVideoException` / `AgoraVoiceException` naming the package to add. Spatial audio, content
inspection and face capture have packages but no façade call yet — each needs a surface of its
own; the video-quality analyser and the encoders are selected by the engine itself once present.

The extension packages themselves are platform-only (`Net.Agora.Extensions.*.Android` / `.iOS`),
published from the binding repositories; add one alongside whichever RTC package you use.

The device suite's RTC flavours gained an extension check that fails when the payloads are missing,
confirmed by building the same app with `-p:AgoraReferenceExtensions=false`;
`samples/Net.Agora.Sample` grew switches for background blur, video enhancement and AI noise
suppression.
