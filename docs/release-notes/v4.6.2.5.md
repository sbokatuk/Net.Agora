## What's changed

`Net.Agora.Video` / `.Maui` and `Net.Agora.Voice` / `.Maui` advance to **4.6.2.5**. Three changes a
consumer will notice, plus the first macOS packages.

### The engine singleton is now guarded rather than shared by accident

Both SDKs hand back a process-wide engine (`sharedEngineWithConfig:delegate:` on Apple,
`RtcEngine.create` on Android, each torn down by a *static* destroy). Constructing a second client
therefore took over the first one's callbacks — the first went quiet with nothing logged — and
disposing either destroyed the engine for both. Neither failure named its cause.

A second construction while one client is alive now throws:

```csharp
using var call = new AgoraVideoOptions { AppId = appId }.CreateClient();
var second = new AgoraVideoOptions { AppId = appId }.CreateClient();
// InvalidOperationException: An AgoraVideoClient is already live in this process. …
```

Share one client across pages, or dispose before creating another. The rule and the fact that
events arrive on SDK threads (marshal before touching UI) are now on `IAgoraVideoClient` and
`IAgoraVoiceClient` themselves.

### A neutral target framework, so shared code can reference the package

Every base façade now also builds plain `net8.0`/`net9.0`/`net10.0`. A shared class library, a
ViewModel project, a test project or a head for a platform Agora does not ship on can reference
`Net.Agora.Video` and program against `IAgoraVideoClient`; constructing the client there throws
`PlatformNotSupportedException` with a message pointing at the platform heads. Previously such a
project could not even restore — it failed NU1202 with no explanation.

The `.Maui` packages are unchanged in this respect: a view needs a platform.

### Exceptions carry what they used to drop

`AgoraVideoException` and `AgoraVoiceException` gained an overload that keeps the platform
exception as `InnerException`, so a native cause is no longer flattened into a message string.

### macOS

The macOS (AppKit) legs ship for Video and Voice, pinned to `Net.Agora.Video.Mac` /
`Net.Agora.Voice.Mac` **4.6.2.2**. Not Mac Catalyst — Agora ships no `maccatalyst` slice — so there
is no MAUI companion for it; the sample under `samples/Net.Agora.Sample.Video.Mac` is a native
AppKit app driving the same cross-platform client.

`SwitchCamera` and `SetSpeakerphone` are no-ops on macOS: those selectors are declared in the
shared header but the macOS engine does not implement them, and a Mac routes audio and video by
device selection instead.

### Also

- The two MAUI view helpers that had `#if ANDROID` / `#elif IOS` with no `#else` now throw there
  instead of silently doing nothing.
- `AgoraVideoOptions.ChannelId` is marked `[Obsolete]`. It was documented as required but never
  read — the channel is a `JoinAsync` parameter, because one client can leave and rejoin a
  different channel without being reconstructed.
